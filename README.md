# Регистрация участников мероприятия

Веб-приложение для управления списком участников мероприятия.
Реализует CRUD-операции - создание, чтение, редактирование, удаление;
валидацию данных, поиск по имени, защиту от дублирования email.

## Технологии

- **Java 17**
- **Spring Boot 3** (Spring MVC, Spring Data JPA)
- **Thymeleaf** — шаблонизатор для HTML-страниц
- **H2 Database** — база данных в памяти
- **Hibernate Validator** — валидация данных (Bean Validation)
- **Maven** — сборка и управление зависимостями

## Запуск

1. Убедиться, что установлен **JDK 17+** и **Maven**.
2. Открыть проект в IntelliJ IDEA (или любой IDE).
3. Запустить класс `EventRegistrationApplication` (главный класс с `@SpringBootApplication`).
4. Открыть в браузере: `http://localhost:8070`

## Функционал

| Операция | URL | Метод | Описание |
|----------|-----|-------|----------|
| Список участников | `/` | GET | Таблица всех участников + строка поиска |
| Поиск по имени | `/search?query=...` | GET | Фильтрация по части имени |
| Форма регистрации | `/register` | GET | Пустая форма для нового участника |
| Сохранение | `/register` | POST | Валидация + сохранение в БД |
| Форма редактирования | `/edit/{id}` | GET | Форма с заполненными данными |
| Сохранение изменений | `/edit/{id}` | POST | Валидация + обновление в БД |
| Удаление | `/delete/{id}` | GET | Удаление участника из БД |

## Валидация

- **Имя** — обязательно (`@NotBlank`)
- **Email** — обязателен, формат email (`@NotBlank`, `@Email`)
- **Email** — уникален в БД (`@Column(unique = true)`)
- При нарушении — ошибки показываются прямо в форме

## База данных

Используется H2 — база данных в оперативной памяти.
При каждом запуске создаётся заново (ddl-auto=create).
Консоль БД доступна по адресу: `http://localhost:8070/h2-console`
